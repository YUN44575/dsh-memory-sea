这片海怎么看

三种问法，按你还记得的东西挑

· 记得一句话 → 上面搜索框，输任意几个字
· 记得大概什么时候 → 标题下面「今天 / 最近 7 天 / 最近 30 天」，点了直接出那一段的回顾
· 记得在哪个对话里 → 左栏点那一段，属于它的星会亮起来

一颗星 = 一句话

谁说的看颜色：我的回复、你说的话、QQ、团队协作、世界日记…
星越大＝这条反复提过；外面的虚线圈＝被标成了长期记忆；越亮＝越近，暗下去的是正在变远的。

点开一颗星

右边出全文、标签、备注。下面还会列出两组：
这件事，别处也提过 —— 别的对话里说得像的几条，点一下跳过去
这段对话里，前后几条 —— 把这句话放回上下文
键盘 ← → 在相邻的星之间走，Esc 一层层退。

整理：星图不适合动手

右上角整理是另一种看法 —— 一条一行、能搜、能排序、能按会话折叠、能多选， 整批收藏 / 隐去 / 打标签。
旁边体检把这堆记忆的状态摊成数字，每张卡都能点：点「重复」就只看重复的那些。
回顾选一段时间出一张卡：那几天什么样、哪句后来再没提过、发过哪些图。

带走

整理页顶上的导出：收藏 / 标签 / 备注 / 隐去 / 归档存成一个文件，换机器点导入就回来了。
记忆本体在 .dsh 里，重装后跑一条 node sea-build/setup.mjs 就重建，不用备份。

看不到某些东西？

① 右上来源：把去掉勾的来源勾回来
② 右上近岸 / 远洋：换一层
③ 被隐去的：「整理」里勾上「看隐去的」

给 AI 用

这个插件也给 AI 开了几个工具：按关键词回忆、回顾某一天、找某段对话、标星。 所以可以直接问 AI「我们之前是不是聊过 X」。

顶栏那四个「换一种看法」（往后看 / 重叠 / 年轮 / 情绪）都是临时换个角度，再点一次回来。
