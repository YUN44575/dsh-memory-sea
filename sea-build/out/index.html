一颗星 = 一段交流

你说的一句话、我回的一段，都收成一颗星。点它 → 右边出全文。星越大＝这条你反复提过、留得越深；外面有虚线圈＝被标成了长期记忆。

左边那列「意识流」= 你的会话

每一条就是 DSH 里的一段对话，按你自己建的工作区分组（鲸鲸的房间 / QQ 聊天 / 工作…）。点一段 → 海里属于它的那串星亮起来，右边列出整段对话的时间线，点任一条跳到那颗星。

两片海，两层

工作海（青蓝）：干活、排障、写东西
陪伴海（粉紫）：鲸鲸的房间、QQ 里聊的那些
还能切两层。两片海说的不是同一件事：
· 她的记忆（SurfCore）有真的遗忘机制 → 深层＝还记得的，浅层＝正在淡忘的
· DSH 会话只是聊天记录、按时间排 → 近岸＝最近几天说的，远洋＝更早说的

星点之间的线，分别是这三样

淡青星座线：语义相近的记忆自动连起来（放大 1.5 倍以上才出现）
暖金放射线（点星后出现）：同一段对话里、时间上挨着的几条
冷蓝放射线（点星后出现）：内容说得像、但不在同一段对话里
线上跑的小光点，方向是「从这颗星 → 它连着的记忆」。

想看「到底谁在说」

右上角来源：可以只留某一类 —— 你说的话、我的回复、QQ、 团队协作（子代理和 Lead 之间来回的那些结论，以前根本看不到）、 世界自己记的生活与旧事、还有世界自己写的日记（它第一人称记的，不是聊天记录）。
面板底下那行隐藏层是 2000 多条系统消息（插件规则、时间上下文、审批流水）： 它们数量比真对话还多，画成星就是噪音，所以不上星 —— 但一条都没丢，能翻、能搜。
某颗星点开后，如果底下多一行「这件事世界那边也记了一笔」， 说明同一句话在世界那边也留下了一条记录 —— 两边的说法可以对上。

想动手整理，别用星图

星图适合「看一眼形状」，不适合「真去整理」。右上角整理打开的是另一种看法： 一条一行、能搜、能排序、能多选，整批收藏 / 隐去 / 打标签。
旁边体检页把这堆记忆的状态摊成几个数字：多少条、多少张图、多少重复、 多少条世界那边也记了一笔、各类来源各占多少 —— 一眼就知道哪里是空的、哪里堆得太多。
收藏、标签、备注会跟着记忆本身走（按稳定 id 存），换台机器、重新生成星图都不会丢。

三种看海的方式

往后看：拖到 +30 / +90 / +365 天，星会按 SurfCore 的衰减规则一颗颗变成空心环 —— 现在还在的东西，多少天之后会没。
情绪：只看心里有过波澜的那些（`emotional` 浓度 ≥ 1），平静的 221 条沉下去，剩下的烧起来。
换一片海：左上角虚线按钮在「DSH 会话」和「SurfCore 记忆」之间切。
